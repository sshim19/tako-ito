# 凧の糸

左の親指で糸を出したり巻いたりし、右の親指で凧を左右に傾けて、今日の風に乗せるゲームです。同じ日は、だれが遊んでも同じ風です。携帯は横向きで、両手で遊びます。

## 遊び方

1. 画面を横向きにして、「揚げる」を押します。制限時間は75秒です。
2. 左の親指を巻き枠の中心より上にずらすと糸が出て、下にずらすと巻き取って凧が上がります。右の親指は横の溝を左右にずらして、凧を傾けます。マウスなら、片方ずつ動かすことができます。
3. 糸が緩むと凧は落ち、突風のときに張りすぎると糸が切れます。
4. 22秒を過ぎれば「しまう」で早めに確定しても構いません。今日の輪をすべて満たしたら、22秒前でも確定します。時間が来ると、そこまでの高さで仕舞います。

最高記録と、その日の最高記録は、この端末に保存されます。0点は記録しません。

終了画面の X と LINE のボタンから、いまの得点をそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
